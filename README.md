## Опис функції
Функція `loyalty_points(amount, is_member)` нараховує 1 бал за кожні повні 20 грн покупки. 
Якщо покупець є учасником програми (`is_member=True`), нараховані бали подвоюються. 
При від'ємній сумі покупки повертається помилка `ValueError`.
